Vielen Dank, dass Sie **RPX Pro** (RolePlay Xtreme Professional Edition) nutzen!

RPX Pro ist eine freie, quelloffene Desktop-Software unter der MIT-Lizenz zur Spielleitung von Pen-&-Paper-Rollenspielen. Die Anwendung arbeitet standardmäßig vollständig lokal („Local-First" / Offline-Betrieb) und überträgt keine personenbezogenen Daten an externe Server.

### 2. Häufige Fragen (FAQ)

- **Werden meine Kampagnen- und Charakterdaten in die Cloud hochgeladen?**  
  Nein. Sämtliche Welten, Karten, Charaktere, Notizen und Spielstände werden ausschließlich lokal auf Ihrem Computer im Standardverzeichnis für Anwendungsdaten gespeichert.
- **Benötigt RPX Pro eine aktive Internetverbindung?**  
  Nein. RPX Pro ist vollkommen offline-fähig. Eine Internetverbindung wird lediglich für optionale externe Werkzeuge oder das Herunterladen von Updates benötigt.
- **Wie funktioniert der Spieler-Bildschirm auf dem zweiten Monitor?**  
  Schließen Sie einen zweiten Monitor an und öffnen Sie den Spieler-Bildschirm über das Menü oder die Schaltfläche. Das Fenster kann auf den zweiten Bildschirm maximiert werden, während Sie auf dem Hauptbildschirm die Spielleitung steuern.
- **Unterstützt RPX Pro benutzerdefinierte Regelwerke?**  
  Ja. Neben den integrierten Vorlagen (D&D 5e SRD, DSA 5 abstrahiert, Generisches Fantasy) können Sie eigene Regelwerke im JSON-Format importieren und anpassen.

### 3. Systemvoraussetzungen

- **Betriebssystem:** Windows 10 Version 1809 (Build 17763) oder höher / Windows 11 (64-Bit x64)
- **Arbeitsspeicher:** Mindestens 4 GB RAM (8 GB empfohlen für große Karten und Soundboards)
- **Festplattenspeicher:** Ca. 250 MB freier Speicherplatz für die Anwendung und Kampagnendaten
- **Bildschirmauflösung:** Mindestens 1366 × 768 Pixel (Full HD 1920 × 1080 empfohlen)

## English

Thank you for using **RPX Pro** (RolePlay Xtreme Professional Edition)!

RPX Pro is a free and open-source desktop application released under the MIT License for game mastering tabletop pen-and-paper role-playing games. The software operates entirely locally by default ("Local-First" / Offline Mode) and does not transmit any personal data to external servers.

### 1. Help & Troubleshooting

- **Documentation:** Detailed guides and architecture documentation are available in [README.md](README.md) and [README_de.md](README_de.md).
- **Bug Reports & Feature Requests:** Please file an issue on the official GitHub repository:  
  👉 **[GitHub Issue Tracker](https://github.com/entertain-and-more/rpx/issues)**
- **Security Inquiries:** Information regarding vulnerability disclosure is available in [SECURITY.md](SECURITY.md).

### 2. Frequently Asked Questions (FAQ)

- **Are campaign and character data uploaded to the cloud?**  
  No. All worlds, maps, characters, notes, and game sessions are stored strictly locally on your computer in your standard application data folder.
- **Does RPX Pro require an internet connection?**  
  No. RPX Pro is completely offline-capable. An internet connection is only needed for optional external tooling or downloading updates.
- **How does the secondary player monitor work?**  
  Connect a second display and open the player screen via the menu or toolbar. The window can be placed and maximized on the secondary screen while you retain full GM controls on your primary screen.
- **Can I use custom rulesets?**  
  Yes. In addition to the built-in templates (D&D 5e SRD, DSA 5 abstracted, Generic Fantasy), custom rulesets can be imported and edited in JSON format.

### 3. System Requirements

- **Operating System:** Windows 10 Version 1809 (Build 17763) or higher / Windows 11 (64-bit x64)
- **Memory (RAM):** Minimum 4 GB RAM (8 GB recommended for large maps and audio)
- **Disk Space:** Approximately 250 MB free disk space for application and campaign data
- **Display Resolution:** Minimum 1366 × 768 pixels (Full HD 1920 × 1080 recommended)
