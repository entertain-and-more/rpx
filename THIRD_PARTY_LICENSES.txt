2. Runtime Architecture & Software Inventory (Canonical 5-Field Schema)
---------------------------------------------------------------------
RPX Pro is a local-first, offline-capable tabletop pen & paper RPG control center
built with Python 3.10+ and PySide6 (Qt6). It operates with zero automated network
egress, storing all campaign worlds, maps, audio triggers, character sheets, and
ruleset templates strictly on the local filesystem in `rpx_pro_data/`.
All runtime components follow the canonical 5-field schema:
(Package:, License:, SPDX:, URL:, Notice:).

Package: python-stdlib
License: Python Software Foundation License Version 2 (PSFL-2.0)

Notice: Core runtime modules (dataclasses, sqlite3, json, pathlib, os, sys, re, urllib, http.server, threading) are provided directly by the Python Standard Library. Zero external runtime supply-chain attack surface.

4. Zero-Copyleft Isolation Guarantee & Unprivileged Execution
-------------------------------------------------------------
- Zero-Copyleft Isolation Guarantee:
  The core architecture of RPX Pro is governed exclusively by permissive licensing
  (MIT License). PySide6 (LGPL-3.0) and pygame (LGPL-2.1) are utilized strictly via
  dynamic linking through unmodified standard Python binary packages in accordance
  with LGPLv3 Section 4 and LGPLv2.1 Section 6. Downstream users may freely inspect,
  substitute, or relink Qt and PySide6 components. User campaign worlds, custom
  ruleset JSON files, cartographic maps, character records, session histories, and
  exported `rpx-campaign-bundle-v1` ZIP files remain 100% proprietary to the user
  with zero copyleft contamination or forced disclosure obligations.

- Unprivileged User-Mode Operation (RunAsInvoker):
  RPX Pro, its CLI runner (`python -m rpx_pro.app --cli`), and its test suites
  operate strictly within standard user space (`RunAsInvoker`). The software requires
  zero administrative elevation, zero root privileges, and zero UAC security prompts.


5. Governance & Runtime Invariants
----------------------------------
RPX Pro enforces ten foundational governance and runtime invariants:

INV-LOCAL-01: 100% Offline & Local-First Zero-Egress
              All world, session, and character data remain in `rpx_pro_data/`.
              Zero external network telemetry, analytics, or background sockets.

INV-USER-02:  Unprivileged User-Mode & Non-Elevation
              Executes strictly under `RunAsInvoker` in user space without admin
              or elevated operating system rights.

INV-DUAL-03:  Dual-Screen State Isolation & Player Screen Mirroring
              Independent display router ensures GM prep, hidden stats, and
              fog-of-war locations never project to the 2nd monitor player view.

INV-RPC-04:   Headless JSON-RPC CLI Interface
              Standardized `stdin`/`stdout` JSON-RPC protocol (`rpx_pro.cli`)
              for autonomous AI agents, script automation, and headless testing.

INV-BUNDLE-05: Deterministic Campaign Bundle Export
              Lossless export of worlds, sessions, and rulesets into portable,
              checksummed `rpx-campaign-bundle-v1` ZIP archives.

INV-PWA-06:   Zero-Cloud Client-Side PWA Companion
              Static Web/PWA companion (`web_companion/`) operates 100% in-browser
              with Service Worker offline caching and zero remote server requests.

INV-COPYLEFT-07: Permissive Licensing & Dynamic Linking
              Core codebase under MIT; PySide6 (LGPL-3.0) and pygame (LGPL-2.1)
              dynamically linked under LGPLv3 §4; zero copyleft contamination.

INV-LLM-08:   Privacy-Guarded AI Prompt Generation
              7 specialized local RPG prompt roles generate text locally for
              clipboard or CLI; zero automated transmission to cloud AI endpoints.

INV-ECO-09:   Modular Sibling Ecosystem Interoperability
              Interoperability with `entertain-and-more` and `open-bricks` sibling
              tools (e.g. KlangpultLight, shared JSON data schemas).

INV-SLA-10:   Contractual Security SLA & Multi-Platform CI
              Committed 48h response / 5d triage vulnerability SLA, validated by
              automated GitHub Actions CI matrices across Ubuntu, macOS, Windows.
