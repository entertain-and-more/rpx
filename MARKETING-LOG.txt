## 1. Executive Summary & Value Proposition
RPX Pro (RolePlay Xtreme Professional Edition) is a comprehensive, open-source, local-first control center for tabletop pen-and-paper RPG sessions (TTRPG). Built with Python 3.10+ and PySide6 (Qt6), it unifies campaign world management, multi-map navigation, second-monitor player screen mirroring, audio/soundboard atmospheres, light effects, combat mechanics, and structured AI prompt generation into a single offline desktop application.

Key Value Proposition:
- **100% Offline & Local-First**: All campaign files, maps, characters, audio assets, and configurations remain strictly on local disk in `rpx_pro_data/`. Zero third-party telemetry, zero cloud lock-in.
- **Dual-Display Player Screen**: Dedicated second-monitor output for players showcasing interactive maps, interior/exterior location views, character party status, mission logs, and ambient light/weather overlays.
- **LLM & Agent Ready**: Headless JSON-RPC CLI (`python -m rpx_pro.app --cli`) over `stdin`/`stdout` allowing autonomous AI agents (Claude, GPT, Gemini, local models) to inspect state and automate campaigns safely.
- **Portable Campaign Bundles (`rpx-campaign-bundle-v1`)**: Zero-loss ZIP export format enabling offline viewing on tablets and phones via the static PWA companion (`web_companion/`).

## 2. Target Personas & Audiences

### Persona 1: Tabletop RPG Game Masters (GMs / DMs)
- **Need**: An all-in-one local session manager running offline during live games with fast map switching, atmospheric audio, and a dedicated player-facing screen.
- **Value Prop**: Seamless multi-monitor orchestration without subscription fees or server downtimes.

### Persona 2: Privacy-Conscious & Offline-First Players
- **Need**: Keeping creative campaign lore, homebrew rulesets, and personal character art completely private and local.
- **Value Prop**: Strict zero-egress architecture; external AI integration is entirely opt-in with manual prompt export.

### Persona 3: AI Tool Builders & Agent Developers
- **Need**: A programmatic backend for LLM-driven dungeon masters, NPCs, and interactive story generation.
- **Value Prop**: Standardized JSON-RPC CLI interface and typed Python API layer with zero external API dependencies.

### Persona 4: Mobile Companion Users
- **Need**: Viewing character sheets, session recaps, and quest logs on mobile devices without setting up servers.
- **Value Prop**: Static Web PWA companion reading local `.zip` bundle exports with full offline restoration.
